## 🇬🇧 English Version

### 📝 Description
Life Simulator is an interactive web-based game where players create a character and navigate through various life stages and events. The game involves managing stats such as health, happiness, smarts, and looks, making decisions about career, assets, activities, and relationships, and experiencing random life events. The goal is to live a life, make choices, and see their consequences, ultimately leading to a game over screen summarizing the character's life.

### ✨ Features
* **👤 Character Creation:** Name your character and choose their gender.
* **📊 Stats Management:** Manage core stats (Health, Happiness, Smarts, Looks) that evolve with your choices.
* **📈 Aging:** Age up your character year by year, encountering new events and opportunities.
* **💼 Career Path:** Find jobs (part-time/full-time, degree/no-degree), get promotions, or face unemployment.
* **🏠 Assets:** Buy and manage assets like houses and cars, each with its own costs and benefits.
* **🤸 Activities:** Engage in various activities: hit the gym, read, party, volunteer, or even dabble in petty crime.
* **❤️ Relationships:** Nurture relationships with parents, find a partner, get married, and start a family.
* **🎓 Education:** Progress from elementary school to university, choosing a major to shape your future.
* **🎲 Random Events:** Experience unpredictable life events that require you to make tough choices.
* **🖥️ Interactive Modals:** Engaging pop-ups for job listings, purchases, activities, and critical decisions.
* **🏁 Game Over:** Reach the end of your character's life and review a summary of their journey.
* **📱 Responsive Design:** Enjoy a seamless experience on various screen sizes, thanks to Tailwind CSS.

### 🚀 How to Play
1.  **Clone the repository (or download the files):**
    ```bash
    git clone [https://github.com/YOUR_USERNAME/Life-Game-Simulator-WEB.git](https://github.com/YOUR_USERNAME/Life-Game-Simulator-WEB.git)
    cd Life-Game-Simulator-WEB
    ```
    (Alternatively, download the ZIP and extract it.)
2.  **Navigate to the directory.**
3.  **Open `index.html`** in your favorite modern web browser (e.g., Chrome, Firefox, Safari, Edge).
4.  **Start your new life!**

### 🛠️ Technologies Used
* **HTML:** For the basic structure of the web pages.
* **CSS:**
    * **Tailwind CSS:** For utility-first styling and responsive design.
    * **Custom CSS (`style.css`):** For additional specific styling, theming, and overrides.
* **JavaScript (`script.js`):** For all game logic, including character management, event handling, UI updates, and interactions.

### 📂 Project Files
* `index.html`: The main HTML file structuring the game's screens (character creation, game screen, game over, modals).
* `style.css`: Contains custom CSS rules, complementing Tailwind CSS for a unique look and feel.
* `script.js`: The heart of the game, containing all JavaScript logic for gameplay mechanics.
